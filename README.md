## ✨ NWC 소개

**NWC**는 웹 화면 개발에 필요한 UI 컴포넌트와 개발 패턴을 제공하여, 프로젝트 전반에서 일관된 사용자 경험과 유지보수 가능한 화면 구성을 돕습니다.

이 Public 저장소는 **일반 개발자, 기업 및 협력사**가 열람할 수 있는 공개 자료를 안내하는 공간입니다. 공개가 승인된 문서, 샘플 및 배포 자료만 이곳에 게시하며, 내부 개발 소스와 제한 자료는 별도의 Private 저장소에서 관리합니다.

> **안내:** Public 저장소에 게시된 자료는 누구나 열람할 수 있지만, 자유로운 재배포나 상업적 이용을 허용하는 오픈소스 라이선스는 아닙니다. 사용 전 [LICENSE](./LICENSE)를 확인해 주세요.

## 🚀 주요 기능

| 영역 | 설명 |
| --- | --- |
| **UI Components** | 입력, 버튼, 그리드 등 화면 개발에 활용하는 컴포넌트 |
| **Layout & Navigation** | 레이아웃, 탭, MDI, 메뉴 등 화면 구조 및 이동 지원 |
| **Sample** | 컴포넌트 및 업무 화면 구현 방식을 살펴볼 수 있는 예제 |
| **Docs** | 사용법, 속성, 이벤트 등 개발 참고 자료 |
| **FAQ** | 개발 과정에서 자주 확인하는 질문과 해결 방법 |

> 실제 제공 기능과 사용 가능한 컴포넌트는 공개된 버전 및 배포 범위에 따라 달라질 수 있습니다.

## ⚡ 시작하기

### 1. 공개 자료 확인

이 저장소에서 공개된 문서와 샘플을 확인하고, 프로젝트 환경에 적합한 컴포넌트를 선택합니다.

### 2. 컴포넌트 사용 방식 살펴보기

NWC 화면은 프로젝트 구성에 따라 웹 컴포넌트를 선언적으로 사용할 수 있습니다.

```html
<!-- NWC 컴포넌트 사용 형태 예시: 실제 실행에는 NWC 로딩 환경이 필요합니다. -->
<nc-input label="검색어"></nc-input>
<nc-button>조회</nc-button>
```

> 위 코드는 컴포넌트 표기 예시이며, 독립 실행 가능한 설치 예제는 아닙니다. 모듈 import 경로, 초기화 및 의존성은 실제 공개된 샘플과 적용 프로젝트 설정을 확인해 주세요.

### 3. 적용 전 확인

- 사용 중인 NWC 버전과 샘플의 호환 여부
- 컴포넌트별 필수 설정과 이벤트 사용 방식
- [LICENSE](./LICENSE)에 따른 사용 가능 범위와 승인 필요 여부

## 🧩 주요 컴포넌트

NWC에서 사용하는 컴포넌트의 예시는 다음과 같습니다.

| 구분 | 예시 | 주요 용도 |
| --- | --- | --- |
| 입력 및 동작 | `nc-input`, `nc-button` | 입력 및 사용자 동작 |
| 데이터 표시 | `nc-grid` | 목록 및 데이터 표시 |
| 화면 구성 | `nc-layout`, `nc-tab` | 레이아웃 및 탭 화면 |
| 내비게이션 | `nc-mdi`, `nc-menu`, `nc-treeview` | 다중 화면, 메뉴 및 트리 구조 |

컴포넌트별 공개 여부, 기능 및 사용 조건은 버전이나 계약에 따라 달라질 수 있습니다.

## 🔐 저장소 운영 안내

| 구분 | Public (현재 저장소) | Private (별도 저장소) |
| --- | --- | --- |
| 열람 | 누구나 가능 | 승인된 계정만 가능 |
| 자료 | 공개 승인 문서, 샘플, 배포 자료 | 내부 소스, 미공개 기능, 제한 자료 |
| 운영 | 공개 전 검토 및 승인 | 권한 관리 및 변경 이력 관리 |

Public 저장소의 파일과 Git 이력은 외부에 노출될 수 있습니다. 내부 소스, 계정 정보, 비밀키, 고객 데이터 및 미공개 자료는 업로드하지 않습니다.

## 📋 이용 안내

NWC 공개 자료는 **기업, 협력사, 일반 개발자**가 확인할 수 있습니다.

| 활동 | 기본 원칙 |
| --- | --- |
| 공개 자료 열람 | 가능 |
| 비상업적 학습·평가·테스트 | LICENSE 조건 내 허용 |
| 소스 수정 및 파생 작업 | 원칙적으로 사전 서면 승인 필요(명시된 예외 제외) |
| 업무·상용 서비스 적용 | 사전 서면 승인 필요 |
| 판매·재배포·제3자 제공 | 사전 서면 승인 필요 |
| Private 저장소 접근 | 별도 접근 승인 필요 |

**저장소 접근 권한과 소프트웨어 사용 허가는 별개입니다.** 상세한 권리·의무와 예외 사항은 [LICENSE](./LICENSE)의 영문 원문을 우선 확인해 주세요.
