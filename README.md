# NWC_PUBLIC — 기본 공개 소스

**공개(Public) · 승인된 기본 소스/샘플/문서**

## 저장소 목적
본사가 외부 공개를 승인한 NWC 기본 컴포넌트 및 문서만 수록합니다. 여기의 내용은 NWC_DEV의 전체 소스나 전체 개발 이력을 의미하지 않습니다.

## 접근 및 허용 범위
누구나 코드 열람, 다운로드, 로컬 학습 및 평가 테스트를 할 수 있습니다. 단, 기업의 실제 업무·상업적 이용은 본사 사전 서면 승인 대상입니다.

## 운영 방식
일반 방문자의 PR이 본사 저장소에 자동 병합되는 것은 아닙니다. 외부 기여는 `CONTRIBUTING.md` 조건을 확인해 주세요.

## 기업 프로젝트 적용
- 내부 업무 시스템, 고객사 구축/납품, 서비스 운영, 상용 제품 통합 및 판매는 별도의 **사전 서면 승인**이 필요합니다.
- GitHub 저장소 읽기 권한·다운로드 권한은 기업 이용허락으로 간주하지 않습니다.
- 공식 문의: [license@example.com — 실제 회사 이메일로 변경]

## 기본 보안 원칙
- 암호, API 토큰, 내부 도메인, 실제 고객/개인정보를 커밋하지 않습니다.
- 승인된 파일만 배포하며 공개 배포 전 의존성·민감정보·제3자 저작권을 검토합니다.
- `.gitignore`는 보안 경계가 아닙니다. 기존 커밋 및 빌드 결과물도 확인해야 합니다.
